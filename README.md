# Human_Cord_blood_Immune_Atlas
Bioinformatics code accompanying "Targeted single-cell proteotranscriptomics reveals immune regulatory states in human cord blood" Includes read processing configs, Seurat v5 QC/clustering, erythroid sub-analysis, pySCENIC regulons, CellChat (CB + adult BM comparison), AUCell signature scoring, and genotype demultiplexing.
